# TGF-RAG-data
Data and experimental results for TGF-RAG.
This release provides the data supporting the TGF-RAG experiments, including Stage A and Stage B filter training samples and labels, generator fine-tuning data, and evaluation data for 3,000 questions under the retrieval-defect settings.

Data splits, construction settings, and source information are included in the archive.

Download: TGF-RAG-data-v1.0.zip
## Data download

The TGF-RAG dataset is available in the following release:

[Download TGF-RAG Dataset v1.0](https://github.com/1796181981/TGF-RAG-data/releases/tag/v1.0)

Open the release page and download the dataset ZIP file under **Assets**.

The archive includes:
- Stage A and Stage B filter training samples and labels.
- Generator fine-tuning data.
- Evaluation data for 3,000 questions under retrieval-defect settings.
- Data splits, construction settings, and source information.
